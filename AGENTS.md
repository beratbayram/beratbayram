# AGENTS.md

This file provides guidance to coding agents when working with code in this repository.

This is the GitHub profile repository: `README.md` is rendered at the top of
github.com/beratbayram. There is no code. `LICENSE` and a stock Node `.gitignore` are the only
other files.

## Editing the README

- It is public and read by recruiters. Keep it short: a two-line headline, one paragraph of
  impact, the featured repo, stack, and contact links.
- Title wording follows the CV ("Frontend Infrastructure Engineer"). Numbers in it (component
  count, products, coverage, people onboarded) come from the CV; don't add or change figures
  without a source.
- Link to repos that are public and unarchived where possible; an archived repo shows a "Public
  archive" badge to visitors.
- The portfolio is at beratbayram.com (not the old `*.vercel.app` URL).
- GitHub-flavored Markdown only; no HTML layout tricks, no badge walls.
- No em dashes. Use commas, colons or `·` separators, as the current text does.
